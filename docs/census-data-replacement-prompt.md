## Task: Replace AI-generated Phase 1 data with real Census/ACS data

### Problem

The three Phase 1 JSON files powering the app were generated by a Gemini
AI pipeline that produced estimated values instead of pulling actual Census
data. For example, Tract 24.47 shows 35.1% Hispanic when the ACS reports
83.9%. Every DVI score, demographic chart, economics card, and triage
ranking in the app is computed from this incorrect data.

### What to do

Build a script that fetches real Census Bureau data for all 269 tracts,
writes replacement JSON files in the exact format the app expects, and
validates against the City of Austin Demographics Hub.

### Architecture context

**Files to replace (exact same paths, exact same field names):**
- `data/phase1_output/audited_demographics_normalized.json`
- `data/phase1_output/audited_property_normalized.json`
- `data/phase1_output/audited_socioeconomic_normalized.json`

**Files that auto-recompute (no changes needed):**
- `data/auditedData.js` — imports the three JSONs, normalizes field names,
  builds indexed Maps
- `data/auditedDvi.js` — recomputes DVI from the Maps
- `data/interim_*.js` — derive UI fields from normalized data
- All UI components — render whatever data is in the JSONs

**The rosetta stone** (region_id ↔ Census tract code):

The complete mapping is at `/tmp/region_tract_rosetta.json` (269 entries).
Each entry has:
```json
{
  "region_id": 1,
  "region_name": "St. Elmo District",
  "tractce22": "002447",     // 6-digit Census tract code
  "name22": "24.47",          // human-readable tract number
  "geoid22": "48453002447"    // full 11-digit FIPS GEOID (state+county+tract)
}
```

**Counties in the dataset:**
- 247 tracts in Travis County (state: 48, county: 453)
- 22 tracts in Williamson County (state: 48, county: 491)

The script must query both counties.

### Step 3: Build the fetch script

Create `scripts/fetch_census_data.cjs`:

```javascript
const fs = require("fs");

const API_KEY = process.env.CENSUS_API_KEY;
if (!API_KEY) {
  console.error("Set CENSUS_API_KEY environment variable");
  process.exit(1);
}

// Load the rosetta stone
const ROSETTA = JSON.parse(
  fs.readFileSync("data/region_tract_rosetta.json", "utf-8")
);

// Group tracts by county for API calls
const TRAVIS_TRACTS = ROSETTA.filter(r => r.geoid22.startsWith("48453"));
const WILLIAMSON_TRACTS = ROSETTA.filter(r => r.geoid22.startsWith("48491"));

// Rate limiting: Census API allows ~500 requests/day without key,
// unlimited with key. Add 200ms delay between calls to be safe.
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

/**
 * Fetch a set of variables from the Census API for all tracts in a county.
 *
 * @param {string} dataset - e.g., "2022/acs/acs5" or "2020/dec/pl"
 * @param {string[]} variables - Census variable codes
 * @param {string} state - state FIPS code
 * @param {string} county - county FIPS code
 * @returns {Map<tractce, {var1: val, var2: val, ...}>}
 */
async function fetchCountyTracts(dataset, variables, state, county) {
  const varsStr = variables.join(",");
  const url = `https://api.census.gov/data/${dataset}`
    + `?get=${varsStr}`
    + `&for=tract:*`
    + `&in=state:${state}&in=county:${county}`
    + `&key=${API_KEY}`;

  const res = await fetch(url);
  if (!res.ok) {
    console.warn(`  API error ${res.status} for ${dataset} county ${county}`);
    const text = await res.text();
    console.warn(`  Response: ${text.slice(0, 200)}`);
    return new Map();
  }

  const data = await res.json();
  // First row is headers, rest are data
  const headers = data[0];
  const tractIdx = headers.indexOf("tract");
  const results = new Map();

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const tractCode = row[tractIdx];
    const obj = {};
    headers.forEach((h, j) => {
      if (h !== "state" && h !== "county" && h !== "tract") {
        const val = row[j];
        obj[h] = val === null || val === "" ? null : Number(val);
      }
    });
    results.set(tractCode, obj);
  }
  return results;
}

/**
 * Fetch all tracts for both counties, merge results.
 */
async function fetchAllTracts(dataset, variables) {
  console.log(`  Fetching ${dataset}...`);
  const travis = await fetchCountyTracts(dataset, variables, "48", "453");
  await delay(200);
  const williamson = await fetchCountyTracts(dataset, variables, "48", "491");
  await delay(200);

  // Merge into a Map keyed by tractce22 (6-digit, zero-padded)
  const merged = new Map();
  for (const [tract, data] of travis) {
    merged.set(tract.padStart(6, "0"), data);
  }
  for (const [tract, data] of williamson) {
    merged.set(tract.padStart(6, "0"), data);
  }
  return merged;
}
```

### Step 4: Fetch and transform for each vintage

For each ACS/Census vintage, fetch the variables, transform them into the
canonical field names the app expects, and store per-region rows.

```javascript
async function buildDemographicsRow(regionId, tractce22, acsData, year, source) {
  const d = acsData.get(tractce22);
  if (!d) return null;

  const totalPop = d.B01003_001E;
  const white = d.B03002_003E;
  const black = d.B03002_004E;
  const asian = d.B03002_006E;
  const hispanic = d.B03002_012E;
  const foreignBorn = d.B05002_013E;

  // Owner-occupied housing
  const totalOccupied = d.B25003_001E;
  const ownerOccupied = d.B25003_002E;
  const pctOwnerOccupied = totalOccupied > 0
    ? (ownerOccupied / totalOccupied) * 100 : null;

  // Rent burden: renters paying 30%+ / total renters
  const rentBurdened = d.B25070_010E;
  const totalRenters = d.B25070_001E;
  const rentBurdenPct = totalRenters > 0
    ? (rentBurdened / totalRenters) * 100 : null;

  // Education: bachelor's or higher / pop 25+
  const bachelors = (d.B15003_022E || 0) + (d.B15003_023E || 0)
    + (d.B15003_024E || 0) + (d.B15003_025E || 0);
  const pop25plus = d.B15003_001E;
  const pctBachelors = pop25plus > 0
    ? (bachelors / pop25plus) * 100 : null;

  // Age 65+ (sum male + female 65+ age brackets)
  // This requires multiple variables — simplified version:
  const pct65 = d.pct_65_plus; // if pre-computed, or compute from age brackets

  const region = ROSETTA.find(r => r.region_id === regionId);

  return {
    year,
    total_population: totalPop,
    median_age: d.B01002_001E,
    pct_hispanic: totalPop > 0 ? (hispanic / totalPop) * 100 : 0,
    pct_white_non_hispanic: totalPop > 0 ? (white / totalPop) * 100 : 0,
    pct_black_non_hispanic: totalPop > 0 ? (black / totalPop) * 100 : 0,
    pct_asian: totalPop > 0 ? (asian / totalPop) * 100 : 0,
    pct_foreign_born: totalPop > 0 ? (foreignBorn / totalPop) * 100 : null,
    pct_owner_occupied: pctOwnerOccupied,
    rent_burden_pct: rentBurdenPct,
    pct_bachelors_degree_or_higher: pctBachelors,
    pct_65_and_over: null, // compute from age bracket variables
    region: region?.region_name || "",
    region_id: regionId,
    audit_source: source,
    audit_confidence: "high",
    audit_notes: `Pulled from ${source} via Census Bureau API`,
    audit_flags: [],
    audit_timestamp: new Date().toISOString(),
  };
}
```

Similar functions for property and socioeconomic rows. The key is that
the output field names EXACTLY match what `auditedData.js` expects after
normalization. Since we're generating canonical names directly, the
normalization pass in `auditedData.js` becomes a no-op (it'll find the
canonical field name on the first `pick()` attempt).

### Step 5: Handle interpolation for intermediate years

For years without direct Census/ACS data (1995, 2005), linearly
interpolate between adjacent anchor years:

```javascript
function interpolateRow(rowA, rowB, targetYear) {
  const t = (targetYear - rowA.year) / (rowB.year - rowA.year);
  const result = { ...rowA, year: targetYear };

  // Interpolate numeric fields
  const numericFields = [
    "total_population", "median_age", "pct_hispanic",
    "pct_white_non_hispanic", "pct_black_non_hispanic", "pct_asian",
    "pct_foreign_born", "pct_owner_occupied", "rent_burden_pct",
    "pct_bachelors_degree_or_higher", "pct_65_and_over",
  ];

  for (const field of numericFields) {
    const a = rowA[field];
    const b = rowB[field];
    if (a != null && b != null) {
      result[field] = +(a + t * (b - a)).toFixed(2);
    } else {
      result[field] = a ?? b ?? null;
    }
  }

  result.audit_source = `Interpolated from ${rowA.year} and ${rowB.year}`;
  result.audit_confidence = "medium";
  result.audit_flags = ["INTERPOLATED"];
  return result;
}
```

### Step 6: Full pipeline

```javascript
async function main() {
  console.log("=== Census Data Fetch Pipeline ===");
  console.log(`Tracts: ${ROSETTA.length} (${TRAVIS_TRACTS.length} Travis, ${WILLIAMSON_TRACTS.length} Williamson)`);

  // ── ACS 5-Year vintages ──
  const ACS_VINTAGES = [
    { apiYear: "2010", vintage: "2006-2010", dataYear: 2010 },
    { apiYear: "2015", vintage: "2011-2015", dataYear: 2015 },
    { apiYear: "2020", vintage: "2016-2020", dataYear: 2020 },
    { apiYear: "2023", vintage: "2019-2023", dataYear: 2023 },
  ];

  const DEMO_VARS = [
    "B01003_001E", "B01002_001E", "B03002_003E", "B03002_004E",
    "B03002_006E", "B03002_012E", "B05002_013E",
    "B25003_001E", "B25003_002E", "B25070_010E", "B25070_001E",
    "B15003_001E", "B15003_022E", "B15003_023E", "B15003_024E", "B15003_025E",
  ];

  const PROP_VARS = [
    "B25077_001E", "B25064_001E", "B25002_001E", "B25002_003E",
  ];

  const SOCIO_VARS = [
    "B19013_001E", "B17001_001E", "B17001_002E",
    "B23025_002E", "B23025_005E", "B19083_001E",
  ];

  const allDemo = [];
  const allProp = [];
  const allSocio = [];

  for (const v of ACS_VINTAGES) {
    console.log(`\nFetching ACS ${v.vintage}...`);

    const demoData = await fetchAllTracts(`${v.apiYear}/acs/acs5`, DEMO_VARS);
    const propData = await fetchAllTracts(`${v.apiYear}/acs/acs5`, PROP_VARS);
    const socioData = await fetchAllTracts(`${v.apiYear}/acs/acs5`, SOCIO_VARS);

    console.log(`  Got demo: ${demoData.size}, prop: ${propData.size}, socio: ${socioData.size}`);

    for (const r of ROSETTA) {
      const demoRow = await buildDemographicsRow(
        r.region_id, r.tractce22, demoData, v.dataYear,
        `ACS ${v.vintage}`
      );
      if (demoRow) allDemo.push(demoRow);

      // Build property row
      const pd = propData.get(r.tractce22);
      if (pd) {
        allProp.push({
          year: v.dataYear,
          median_home_value: pd.B25077_001E,
          median_rent_monthly: pd.B25064_001E,
          total_housing_units: pd.B25002_001E,
          vacancy_rate: pd.B25002_001E > 0
            ? (pd.B25002_003E / pd.B25002_001E) * 100 : null,
          region: r.region_name,
          region_id: r.region_id,
          audit_source: `ACS ${v.vintage}`,
          audit_confidence: "high",
          audit_flags: [],
          audit_timestamp: new Date().toISOString(),
        });
      }

      // Build socio row
      const sd = socioData.get(r.tractce22);
      if (sd) {
        const povertyRate = sd.B17001_001E > 0
          ? (sd.B17001_002E / sd.B17001_001E) * 100 : null;
        const unempRate = sd.B23025_002E > 0
          ? (sd.B23025_005E / sd.B23025_002E) * 100 : null;

        allSocio.push({
          year: v.dataYear,
          median_household_income: sd.B19013_001E,
          poverty_rate: povertyRate != null ? +povertyRate.toFixed(1) : null,
          unemployment_rate: unempRate != null ? +unempRate.toFixed(1) : null,
          gini_coefficient: sd.B19083_001E,
          region: r.region_name,
          region_id: r.region_id,
          audit_source: `ACS ${v.vintage}`,
          audit_confidence: "high",
          audit_flags: [],
          audit_timestamp: new Date().toISOString(),
        });
      }
    }
  }

  // ── Decennial Census pulls (2020, 2010, 2000) ──
  // Add decennial data for race/population at exact Census years
  // These provide higher-confidence anchor points for demographics
  // TODO: Add 2020 PL, 2010 SF1, 2000 SF1 pulls with their respective
  // variable codes (differ per decade)

  // ── Interpolation for intermediate years ──
  console.log("\nInterpolating intermediate years...");

  // Group rows by region_id, sort by year, interpolate gaps
  function interpolateGaps(rows, targetYears) {
    const byRegion = new Map();
    rows.forEach(r => {
      if (!byRegion.has(r.region_id)) byRegion.set(r.region_id, []);
      byRegion.get(r.region_id).push(r);
    });

    const interpolated = [];
    for (const [rid, regionRows] of byRegion) {
      regionRows.sort((a, b) => a.year - b.year);
      for (const ty of targetYears) {
        // Skip if we already have this year
        if (regionRows.some(r => r.year === ty)) continue;
        // Find surrounding rows
        const before = regionRows.filter(r => r.year < ty).pop();
        const after = regionRows.find(r => r.year > ty);
        if (before && after) {
          interpolated.push(interpolateRow(before, after, ty));
        }
      }
    }
    return interpolated;
  }

  const demoInterp = interpolateGaps(allDemo, [1995, 2005]);
  const propInterp = interpolateGaps(allProp, [2005]);
  const socioInterp = interpolateGaps(allSocio, [2005]);

  allDemo.push(...demoInterp);
  allProp.push(...propInterp);
  allSocio.push(...socioInterp);

  // Sort all rows by region_id, then year
  allDemo.sort((a, b) => a.region_id - b.region_id || a.year - b.year);
  allProp.sort((a, b) => a.region_id - b.region_id || a.year - b.year);
  allSocio.sort((a, b) => a.region_id - b.region_id || a.year - b.year);

  // ── Write output ──
  console.log("\nWriting output files...");
  console.log(`  Demographics: ${allDemo.length} rows`);
  console.log(`  Property: ${allProp.length} rows`);
  console.log(`  Socioeconomic: ${allSocio.length} rows`);

  // Back up existing files
  const DEMO_PATH = "data/phase1_output/audited_demographics_normalized.json";
  const PROP_PATH = "data/phase1_output/audited_property_normalized.json";
  const SOCIO_PATH = "data/phase1_output/audited_socioeconomic_normalized.json";

  [DEMO_PATH, PROP_PATH, SOCIO_PATH].forEach(p => {
    if (fs.existsSync(p)) {
      fs.copyFileSync(p, p + ".bak");
      console.log(`  Backed up ${p}`);
    }
  });

  fs.writeFileSync(DEMO_PATH, JSON.stringify(allDemo, null, 2));
  fs.writeFileSync(PROP_PATH, JSON.stringify(allProp, null, 2));
  fs.writeFileSync(SOCIO_PATH, JSON.stringify(allSocio, null, 2));

  console.log("\n=== Done ===");
  console.log("Run the app and verify DVI scores, demographic charts, and economics cards.");
}

main().catch(console.error);
```

### Additional notes

**Census API values of -666666666 mean "not available"** — treat as null.

**Values of 999999 in COA Hub data mean "suppressed"** — treat as null.

**The rent burden variable B25070_010E** represents "renters paying 30%
or more of income on rent." The denominator is B25070_001E (total renters
computed from the same table). Divide to get the percentage.

**65+ population** requires summing multiple age bracket variables. For
ACS 5-year, use B01001_020E through B01001_025E (males 65+) plus
B01001_044E through B01001_049E (females 65+), divided by total
population.

**Eviction data** is NOT in the Census. The `eviction_filing_rate` field
should be set to null in the new data, with a note that it comes from
Eviction Lab (a separate source not available via the Census API). If
you have Eviction Lab data separately, it can be merged in a second pass.

**SNAP participation** is available in ACS table B22003 or subject table
S2201, but subject tables use a different API endpoint
(`/acs/acs5/subject`). Handle separately or set to null initially.

### Constraints
- Back up all three JSON files before overwriting
- Output field names must exactly match the canonical names in
  auditedData.js (listed in the normalization section)
- Every row must have `region_id`, `year`, `region` (name), plus the
  data fields
- `audit_source` should accurately reflect the Census vintage
- `audit_confidence` should be "high" for directly fetched data,
  "medium" for interpolated years
- `audit_flags` should include "INTERPOLATED" for interpolated rows,
  empty array for direct pulls
- Handle API errors gracefully — log and skip, don't crash
- Respect Census API rate limits (add delays between calls)
- The script should be re-runnable (idempotent) — running it twice
  produces the same output
